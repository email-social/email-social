# Email Social

Email Social turns the mailbox you already have into a chat. Conversations instead of folders, bubbles instead of headers, and every message you send is still a normal e-mail that anyone can read in any client. There is no server of ours: your mailbox is the only place your messages live.

- Protocol specification: `spec/` (CC BY 4.0)
- Library, bridge and web client: `packages/` (Apache-2.0)
- Work items and their acceptance tests: `tasks/`

Status: `es-core` (Task 1) and the local bridge with its web client (Task 2) are in place. To try it, see [`docs/TRY-IT.md`](docs/TRY-IT.md).
